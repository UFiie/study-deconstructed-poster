# study-deconstructed-poster

**中文名：解构研究海报**

一个把单张照片转化为“摄影记录 + 水彩技术爆炸图”研究海报的图片生成 Skill。

它不是普通拼贴，也不是简单插画海报，而是将照片中的主体提炼为一页具有**档案感、研究感、展览感**的视觉成品：上半部分保留真实摄影，下半部分把同一主体解构为等轴测水彩爆炸图，并配以编号标注、色板、比例尺和制图信息。

---

## ✨ Skill 简介

`study-deconstructed-poster` 适合将以下类型的照片转化为高完成度海报：

- 建筑摄影
- 村落 / 房屋 / 聚落
- 悬崖 / 海岸 / 地形
- 框架式构筑物
- 风景装置 / 景观节点
- 具备明确结构关系的对象或场所

最终画面会形成一种非常鲜明的双层表达：

1. **上半部分是原貌记录**：保留真实光影、材料和气氛；
2. **下半部分是理性解构**：用水彩淡彩和技术图语言重新组织主体；
3. **整体呈现档案研究海报气质**：温和、克制、精致、有留白。

---

## 🧭 核心设计逻辑

这个 Skill 的核心，不是“给照片加说明文字”，而是建立一套完整的视觉研究逻辑：

- **摄影是证据**：上半部分保留对象在真实世界中的状态；
- **爆炸图是分析**：下半部分把对象拆解为可阅读的结构层；
- **排版是秩序**：编号、引线、色板、比例尺与档案编号共同建立研究感；
- **水彩是温度**：避免冷硬 CAD 感，让技术图也保有情绪和诗意。

## 🖼️ 输出效果特征

使用这个 Skill 生成的海报，通常会具备以下特征：

- 竖版单张海报
- 上下严格 1:1 分区
- 上半部分为保真的摄影图像
- 下半部分为等轴测技术爆炸图
- 3–6 层悬浮分解结构
- 水彩淡彩 + 细墨线风格
- 空心编号圆点与细引线注释
- 4–6 色自然色板条
- 比例尺、指北针/坐标、研究编号
- 暖米白纸底与轻微纸张纹理
- 整体类似展览研究板或档案海报

## 🧱 版式规则

Skill 的基础版式固定如下：

- **整体为竖版海报**
- **上下严格对半，各占 50%**
- **上半部分保留原照**
- **下半部分进行水彩技术爆炸图重绘**

这意味着它强调的是一种稳定、理性、可复用的研究海报框架，而不是每次都随意变版。

---

## 🔍 下半部分会生成什么？

下半部分是这个 Skill 的核心亮点，通常会包含：

- 爆炸分层主体（3–6 层）
- 一层完整外观
- 一层内部结构 / 框架
- 其余层为地基、地貌、水文、景观或功能层
- 引线注释与编号系统
- 小型等轴测辅图
- 色板条
- 比例尺
- 指北针或简化坐标
- 档案编号 / 年份

这些元素组合后，会让整张图看起来像一页精心设计的视觉档案，而不是一张普通海报。

## 🎯 这个 Skill 的优势

### 1. 结构逻辑很强
它不仅好看，而且能够把照片中的主体“研究化”。

### 2. 风格辨识度高
“上摄影、下爆炸图”的形式非常鲜明，适合做系列作品。

### 3. 情绪与理性并存
既有摄影的真实感，也有水彩图的温度和技术图的秩序。

### 4. 很适合做作品集与展示页
特别适合用于：
- 作品集视觉页
- 展览辅助图版
- 建筑 / 景观 / 艺术类展示
- 社交平台风格化发布

---

## 🚫 不适合的方向

为了保持风格纯度，这个 Skill 不适合：

- 卡通化角色海报
- 赛博 UI 风格
- 纯 3D 建模爆炸图
- 高饱和商业广告图
- 大段文字型信息图
- 随意涂鸦拼贴海报
- 过度复杂的工程施工图纸风格

它追求的是：**研究感、编辑感、纸上档案感**，而不是工业制图教科书或商业宣传物料。

## 📎 补充说明

这个 Skill 最适合以下来源照片：

- 主体清晰
- 构图完整
- 环境关系明确
- 有结构可拆
- 材料或地貌特征鲜明

如果上传的照片主体过于模糊、内容过杂、或没有明显结构中心，下半部分的爆炸图表现力会相对减弱。

因此，建议优先使用：

- 建筑
- 景观节点
- 海岸地形
- 框架装置
- 村落 / 设施 / 小型聚落
- 有明确对象层次的照片
